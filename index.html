문자 중심으로 진행됩니다

다음 차수 모집 알림과 여석 알림은 메일보다 빠른 문자 기준으로 운영합니다. 자동 문자는 Solapi를 이용합니다.

  1. 1. 예약 대기

    달력에서 원하는 날짜를 선택하고 이름, 연락처, 케틀벨 경험을 남깁니다.

  2. 2. 선착순 6명 결제 안내 문자

    해당 차수 모집이 열리면 대기 순서 기준 선착순 6명에게 결제 안내 문자가 발송됩니다.

  3. 3. 여석 발생 시 순차 발송

    취소나 미결제로 여석이 생기면 백관장이 확인 후 다음 대기자에게 문자 발송을 승인합니다.

  4. 4. 결제 완료 후 수업 안내 문자

    결제 완료 시 수업 일정, 장소, 준비물 안내 문자가 자동 발송됩니다.

  5. 5. 수업 종료 후 노션 교재 자동 발송

    수업 종료 후 복습용 노션 교재 링크가 문자로 자동 발송됩니다.

  6. 6. 복습 영상은 별도로 발송

    비공개 유튜브 복습 영상 링크는 백관장이 수업 후 직접 별도로 발송합니다.

FAQ

자주 묻는 질문

예약 대기 신청하면 바로 결제해야 하나요?＋

아닙니다. 예약 대기 신청은 원하는 날짜에 대기 등록을 해두는 절차입니다. 결제는 해당 날짜 모집이 열렸을 때 선착순 안내 문자를 받은 분부터 진행됩니다.

예약 대기 인원은 볼 수 있나요?＋

네. 각 날짜별 예약 대기 인원을 확인할 수 있게 운영합니다. 다만 결제 안내 문자를 받은 뒤 결제까지 완료해야 자리가 확정됩니다.

여석이 생기면 어떻게 되나요?＋

취소나 미결제로 여석이 생기면 백관장이 확인한 뒤 다음 대기자에게 순차적으로 결제 안내 문자를 발송합니다.

수업 후 복습 자료는 어떻게 받나요?＋

수업 종료 후 복습용 노션 교재 링크가 문자로 자동 발송됩니다. 복습 영상 유튜브 링크는 백관장이 별도로 발송합니다.
